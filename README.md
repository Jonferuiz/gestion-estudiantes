# Sistema de Gestión de Estudiantes API

Una API REST-ful construida con Python y FastAPI para la gestión y nivelación de estudiantes.

## Instalación

1. Clona el repositorio:
   `git clone https://github.com/tu-usuario/gestion-estudiantes.git`
2. Crea un entorno virtual:
   `python -m venv venv`
3. Activa el entorno virtual e instala las dependencias:
   `pip install fastapi uvicorn pydantic`

## Ejecución

Para iniciar el servidor de desarrollo, ejecuta:
`uvicorn app:app --reload`

El servidor estará disponible en `http://127.0.0.1:8000`.
